# Cuaderno · Física y Cálculo

Web estática de estudio con teoría, preguntas, pistas y soluciones justificadas.

```text
149 ejercicios · 645 pasos · 33 documentos
```

1. En https://github.com/new crea un repositorio llamado cuaderno.
   Selecciona Public. Puedes dejar sin marcar Add README, porque ya incluimos uno.
2. Descomprime Cuaderno-GitHub-Pages.zip. Entra dentro de la carpeta para-subir.
3. En el repositorio: Add file > Upload files. Arrastra TODO EL CONTENIDO de
   para-subir: los archivos y las carpetas vendor, library y figures.
   index.html debe quedar directamente en la raíz del repositorio.
   No subas el ZIP cerrado ni una carpeta para-subir que envuelva todos los archivos.
4. Pulsa Commit changes para confirmar la subida en la rama main.
5. Abre Settings > Pages. En Build and deployment, elige:
   Source: Deploy from a branch
   Branch: main
   Folder: / (root)
   Pulsa Save.
6. Espera a que GitHub publique el sitio. La dirección será:
   https://TUUSUARIO.github.io/cuaderno/
   Sustituye TUUSUARIO por tu usuario real. Settings > Pages mostrará el enlace.

SI QUIERES TUUSUARIO.GITHUB.IO SIN /CUADERNO/

Crea el repositorio con el nombre exacto TUUSUARIO.github.io en lugar de cuaderno.
Los archivos y la configuración main / (root) son los mismos.

QUÉ SUBIR

El contenido completo de para-subir. El archivo .nojekyll también está incluido.
Las fuentes de las fórmulas se sirven localmente en formato WOFF2.
La web utiliza rutas relativas y navegación con #, compatible con repositorios
de proyecto. No hay CNAME porque el dominio gratuito github.io es automático.

USO EN TABLET, IPAD Y TELÉFONO

Abre la dirección HTTPS publicada. Puedes copiar pasos, resultados y teoría;
hay formatos Texto y fórmulas y Markdown + LaTeX. Para conservar la composición
de las fórmulas al importarlas en Goodnotes, usa Imprimir / PDF.
Favoritos, notas y progreso se guardan en cada navegador. Mi progreso permite
exportar e importar una copia. Al cambiar desde la web anterior a github.io,
exporta primero tu progreso en la web anterior y luego impórtalo en la nueva.

ALCANCE DE LA PUBLICACIÓN

GitHub Pages gratuito usa repositorios públicos y la web queda accesible por enlace.
El paquete no contiene sesiones de Moodle ni credenciales. Los identificadores
personales de la tabla de datos de prácticas están ocultos. Conserva las fuentes
y atribuciones de los documentos; las explicaciones son material de apoyo y
las erratas o datos insuficientes se indican dentro de cada ejercicio.
