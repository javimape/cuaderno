# Cuaderno · Física y Cálculo

Web de estudio con 149 ejercicios, 645 pasos guiados, 102 dibujos explicativos nuevos en 81 ejercicios y 33 documentos de clase.

Incluye teoría, preguntas, pistas, explicaciones, comprobaciones y copia de texto o LaTeX. Compatible con tamaños de móvil y tablet. «Imprimir / PDF» permite guardar las soluciones para una app de apuntes. Favoritos, notas y progreso se conservan en cada navegador y se pueden exportar e importar.

## Publicación

GitHub Pages: **Settings → Pages → Deploy from a branch → main → / (root)**.

Dirección: https://javimape.github.io/cuaderno/

Los archivos están en la raíz para permitir su subida directa desde el navegador. No se necesita instalación ni compilación. `index.html` abre la aplicación; `app.js`, `copy.js` y `styles.css` controlan la interfaz; `data.json` contiene el material didáctico. Los PDF y esquemas enlazados se sirven desde este mismo repositorio.

Las explicaciones son material de apoyo, sin carácter oficial. Las posibles erratas o datos insuficientes se señalan en cada ejercicio. Se conservan las referencias al material de Moodle. Los identificadores personales de la tabla de datos de prácticas están ocultos.

Dependencias: KaTeX y marked, con sus licencias MIT incluidas.

## Dibujos de apoyo

Los esquemas distinguen geometría real, superficies auxiliares, sentidos y casos representativos. Incluyen guías conectadas con los pasos de solución. Se pueden ampliar, copiar como imagen o guardar en PNG a 1520 píxeles para aplicaciones de apuntes; se incluyen al imprimir en PDF. Las guías se incluyen al copiar la solución como texto. Los SVG se integran en `data.json`, por lo que la carpeta de subida sigue teniendo menos de 100 archivos.
